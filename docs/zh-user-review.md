# 使用者视角审查（1.0.3）

按「只看中文说明、只做该做的事」过了一遍扩展和部署。下面是改过的体验，以及还留着的限制。

## 图标

工具栏、扩展列表、登录页、自动填充按钮和保存提示用同一枚标记：陶土色圆角方块，里面是一把钥匙和一小段计时弧。源文件是 `apps/browser/src/images/zh-mark.svg`。它和官方蓝色盾牌不是同一个图形，两个扩展并排时能分开。

## 设计

浅色默认是奶油底（`#FAF9F5`）和陶土色强调（`#C4532A`），字是暖炭色（`#3D3929`），图标是暖灰（`#5E5D59`），不再用纯黑或冷灰。深色是 `#262624` 底、`#30302E` 表面、`#3E3E38` 边、`#F5F4EE` 字。字体栈在 Inter 后面加了苹方、思源黑体和微软雅黑，中文行高 1.5。验证码用等宽大字，按 `123 456` 分组，旁边是倒计时环，点卡片就复制。

对比：白字在 `#C4532A` 上大约 4.5:1；暖炭字在奶油底上高于 7:1；深色奶油字在 `#262624` 上高于 12:1。

## 体验改动

| 以前 | 现在 | 原因 |
| --- | --- | --- |
| 登录要选地区、自托管、记住邮箱、通行密钥、SSO、创建账户 | 只剩服务器 URL、邮箱、继续，然后是主密码 | 私有部署用不到那些入口 |
| 扩展里可以注册 | 注册路由直接回到登录。账户在网页或管理页创建 | 插件不负责开户 |
| 第一次打开有欢迎页、轮播、设为默认密码管理器 | 这些都不再出现 | 功能优先 |
| 密码库欢迎卡片、设置红点、高级功能广告、下载 App | 不再显示 | 同样的原因 |
| 超时默认「浏览器重启」 | 新安装默认「从不」，动作「锁定」 | 按使用习惯 |
| 跟随系统深色，图标近黑 | 新安装默认浅色；图标跟字色走 | 和陶土色配 |
| 验证码保存失败只有一行小字，列表操作失败没提示 | 服务器写失败会弹出「无法保存到服务器，请检查网络后重试。」本地不会假装成功 | 密码和验证码必须在服务器上 |
| 和官方扩展同名、同快捷键 | 名称「Bitwarden 验证器版」，快捷键不占用官方那一组 | 可以同时安装 |
| 自动填充菜单跟着系统深色，白网页上是一块炭黑 | 菜单跟扩展主题。没选深色时，白网页和黑网页都是奶油底、暖字、陶土色 | 默认不要黑色 |

## 数据放哪

- 登录、卡片、身份、笔记、SSH、文件夹：原有密码库接口，加密后存在 Vaultwarden。
- 验证器页的条目（名称、密钥、算法、位数、周期、排序）：`POST/PUT/DELETE /authenticator`，加密后存在服务器。浏览器里的快照只是同步缓存，写入成功之后才更新。
- 服务器地址、主题、超时、自动填充、语言：存在扩展的本地存储，更新扩展不会清掉。账户级的 URI 匹配如果用户改过，仍走原来的账户设置。未改过时，新安装按主机匹配。

## 主机匹配

未单独设置匹配方式时，默认是「主机」，不是基础域名。保存登录时记下的是页面完整地址（例如 `https://gitlab.pub.monite.cn/users/sign_in`），不会收成 `monite.cn`。

用这条地址做的检查：

- `https://gitlab.pub.monite.cn/explore` 可以匹配
- `https://monite.cn`、`https://pub.monite.cn`、`https://other.pub.monite.cn`、`https://gitlab.pub.monite.cn.evil.test` 不匹配
- 自动填充设置里默认显示「主机」
- 验证器条目本身不带网站匹配；从保存提示新建的登录用上面的规则

## 还没改掉的限制

- 通行密钥的依赖方不能是 IP。
- 基本认证自动填充仍要每一条 URI 都显式选匹配方式，而且要自己打开那个选项。
- 网页保险库仍是镜像里的英文版，开户在网页上做。
- 两个扩展同时开时，页面上可能各出一条保存提示，需要点自己那一条。
- Firefox 临时载入退出后会卸掉。
